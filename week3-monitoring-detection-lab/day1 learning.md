# AWS Logging Basics

## What I did:

- Explored AWS CloudTrail service
- Opened Event History in CloudTrail
- Observed AWS activity logs
- Generated new AWS actions (S3/IAM activity)
- Refreshed logs to observe new events

---

## Key Learnings:

- AWS records all important account activities
- Logs help track user and service actions
- CloudTrail acts as an audit logging service
- Logging is critical for security investigations
- Every AWS action leaves a trace

---

## Hands-on Summary:

- Opened CloudTrail dashboard
- Viewed:
  - Login events
  - IAM activity
  - S3 operations
  - EC2 actions
- Generated test activity and verified logs

---

## Mistakes to Avoid:

- Ignoring logs during investigations
- Not monitoring AWS activity regularly
- Assuming AWS actions are not traceable

---

## Security Insight:

- Logs act as digital evidence
- CloudTrail helps identify suspicious activity
- Logging is essential for incident response
